# TCP port status


** TCP port status by simple check.yaml** - Шаблон мониторинга TCP портов для Zabbix версии 7.

Проверка доступности порта TCP методом простых проверок. Элементы данных и триггеры обнаруживаются автоматически,

исходя из значения макроса {$TCP_PORTS}. Синтаксис указания портов в макросе - любой, разделитель - любой, текст игнорируется.

Порты ниже 20 и выше 65535 также игнорируются. Уникальность значений портов обеспечивается автоматически.

В целях безопасности, максимальное количество корректно заданных портов искусственно ограничено величиной, равной 20.

Максимальная длина значения макроса в Zabbix равна 2048 символов.
